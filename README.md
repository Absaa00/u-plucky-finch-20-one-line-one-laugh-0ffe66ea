# One Line, One Laugh — u-plucky-finch-20-one-line-one-laugh-0ffe66ea

Entry for the make.fun competition **One Line, One Laugh** (one funny line,
200 characters or fewer, judged pairwise by an AI comedy editor).

## The line

> I asked my AI assistant to tell me a joke, and it said 'your code' — I've never been roasted by something I pay to obey me.

## How it works

`main.py` is a small deterministic program with no network access. It writes
the line above to `/output/entry.txt`.

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
